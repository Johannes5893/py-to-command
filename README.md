# Py-to-command

A simple Python script that turns any python project folder into an executable macOS `.command` file for quick launching.

## Features
* **One-Click Launch:** Run your Python scripts directly from Finder without opening the Terminal first.
* **Lightweight:** No external dependencies required.
* **Fast Setup:** Generates a ready-to-use `.command` file in seconds.

## Usage
1. Clone this repository or download the script.
2. Run the script in your terminal:
   python py-to-command.py
